🚀 Chat App API

Welcome to the Chat Application! The API is running successfully.

Available API Endpoints:

POST /api/auth/register
Register a new user
POST /api/auth/login
Login with existing credentials
GET /api/auth/verify
Verify JWT token (requires authentication)

Test the API:

You can test the endpoints using tools like Postman or curl:

curl -X POST http://localhost:8080/chatapp/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"testpass","displayName":"Test User"}'
